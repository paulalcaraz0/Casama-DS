# data_science/

Code and outputs for the Data Science final project, **Casama Bill Pulse**.
The full documentation is the repository's main [README](../README.md).

- `psa_client.py`: reusable PSA OpenSTAT API client
- `casama_bills_analysis.py`: pulls the data and computes every metric into `output/`
- `make_charts.py`: draws the README charts into `charts/`
- `VIDEO_SCRIPT.md`: presentation script

Run from this folder: `python3 casama_bills_analysis.py && python3 make_charts.py`
